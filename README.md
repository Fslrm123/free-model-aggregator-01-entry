Rating-ordered free-model aggregator: a Node 22 server that serves OpenAI Chat Completions and Anthropic Messages over ten simulated free-tier providers, planning the whole 20-request workload up front and routing each request to the best free model that can serve it.

## Run it

```sh
node main.ts --list
```
